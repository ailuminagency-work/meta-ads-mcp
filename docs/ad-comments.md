# Registered ad to Page comments

The bridge reads an existing registered AD with an independently selected Marketing USER credential, verifies the actual account and creative, and reads the creative's effective_object_story_id. It then requires an already registered same-client/same-app Facebook Pages POST and a separately selected PAGE credential. No returned story/comment ID enrolls an asset or transfers grants between provider families.

Primary references inspected October 16, 2026: the Ad Creative reference updated August 6, 2026 defines effective_object_story_id as the Page post used by organic or unpublished ads, distinct from effective_instagram_media_id (https://developers.facebook.com/documentation/ads-commerce/marketing-api/reference/ad-creative). The current v26 Object/comments reference states that User tokens return empty Post comments, comment IDs require the Page MODERATE task, and parent object permissions apply (https://developers.facebook.com/docs/graph-api/reference/v26.0/object/comments).

The Page reader verifies current post.from ownership and fetches only bounded top-level comments. It projects only separately registered and authorized COMMENT children. Author names/IDs, paging URLs, arbitrary fields, unregistered comments and implicit moderation authority are withheld. A partial bounded registered subset is always labeled complete_inventory:false. Reading an unpublished ad post is supported; existing reply/moderation tools retain their separately reviewed published-post restrictions and human approvals.

Both READ permits finish successfully, then ONE atomic readonly transaction compares the union of both original authorization snapshots and the exact encrypted credential envelopes actually used by both reads, all member indices, provider actual-user privacy locks and lifecycle locks before any comments leave the service. Sequential independent final checks are insufficient. Fixture tests prove the local two-credential boundary and withdrawal handling; they do not establish live client grants, App Review or actual Meta comment visibility.
