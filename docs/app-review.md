# App Review and access evidence

Use meta-capability-matrix.md as the endpoint inventory, not a blanket approval request. For each enabled product record minimum permissions, token type, Page tasks, standard/advanced access applicability, app review status, business verification, tech-provider eligibility, marketing access tier and client asset consent.

Evidence must come from current official documentation and the actual app dashboard. Connection eligibility attestations are server-owned, requirement-specific, time-bounded and source-backed. They cannot be supplied in a tool call. Unknown eligibility stays UNVERIFIED. Build screencasts and test instructions against consenting test assets; submit only after explicit authorization.

This branch has not submitted review, changed app publication or proved external-client access. The 17 primary-verified new endpoint contracts are not 17 live available capabilities. Many entries remain HOLD pending endpoint-specific research and implementation.
