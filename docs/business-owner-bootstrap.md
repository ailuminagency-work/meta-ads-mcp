# Protected client Business ownership bootstrap

`LUMIN_BUSINESS_OWNER_BINDINGS_ENABLED=true` enables the authenticated human review UI at `/platform/business-owner/:client/:business/:connection`; it also requires the platform flag, numeric configured `META_APP_ID` and a session secret of at least32 characters. It is off by default. No MCP tool accepts ownership artifacts or creates this authority.

Declare the client and its META_BUSINESS root first, then enroll an actual same-app Facebook Business USER connection through the deployment-owned OAuth profile. OAuth membership proves access only. A current client admin must independently review a client ownership artifact in the protected UI. The file stays local: only its SHA256 reference is submitted. This is a human assertion, not automatic document-content verification. The artifact binds exact tenant/client/Business/app/source connection identity, exact encrypted credential digest and issuer revision, with a maximum24-hour expiry. Source access/root/grants must be fresh within five minutes at issuance. Billing/spending requires separate authority.

The immutable review reference plus client revision prevents replay or concurrent duplicate issuance. Every dependent authorization loads the current artifact, issuer, source connection and credential metadata; current source revocation, issuer role/revision change, artifact expiry/revocation or cross-app substitution denies. Core execution binds these records to the authorization snapshot and transaction comparisons. Revocation retains the pointer tombstone so it cannot fall back to an old trusted ID.

`businessOwnerAttestations` contains issuer identity and hashed document provenance, is covered by privacy cleanup and has finite authorization validity of at most 24 hours. The current bootstrap plan installs no storage TTL on this collection; expiry is enforced by authorization checks, and subject-bound records are removed by privacy cleanup. Do not invent a TTL deployment policy. Existing explicitly trusted bootstrap Business IDs without a new pointer retain their separate provenance; public declarations and OAuth never create such trusted ownership by inference.
