# Default-off Gemini bounded text analysis

This is an optional text-analysis adapter, not a grounded competitor-search service. No provider account, credential, budget or paid request has been activated. Grounded Google Search, URL context, files, media, caches and tools remain unavailable in this adapter: the retrieved primary Search documentation permits multiple model-generated searches but does not establish a request-level search billing ceiling.

Primary contracts reviewed:

- [GenerateContent REST and generation/usage fields](https://ai.google.dev/api/generate-content): fixed model endpoint, candidate count, maximum output tokens, thinking budget and response token counts.
- [CountTokens](https://ai.google.dev/api/tokens): the exact text request is counted before generation and rejected above the local input ceiling.
- [Current pricing](https://ai.google.dev/gemini-api/docs/pricing): the current table includes standard `gemini-2.5-flash-lite` text input and output pricing. The server configuration must carry a separately reviewed price observation and expiry no longer than 24 hours; values are not treated as permanently current.

The supported request is one unsearched textual analysis, with no source documents, one candidate, at most 4,096 input tokens and 2,048 output tokens, and thinking disabled. The request body is server constructed. Provider extras, thoughts, tools, unsupported usage and error markers never become model output. Returned text is bounded, credential-shaped strings are rejected, and its provenance explicitly says unsearched model analysis. A request hash is a local provenance reference, not a web citation.

The existing hard-cap provider registry is unchanged. Gemini requires the separate `registerBoundedRequest` admission path. Both `providerHardCostCap` and provider idempotency are explicitly false. The quote is a conservative local token-price reservation, not a guaranteed provider invoice amount. The actual authenticated human review page requires an additional acknowledgment of that distinction, bound to the reviewed job revision and plan. Approval of Google Cloud infrastructure spending does not authorize this optional paid service.

The validated research job is durably marked attempted and reserves its local estimate before any provider call. The trusted executor passes the existing job context and current-authority callback; the adapter never receives model-supplied tenant/operator/job attribution. Current job, actor, approval, provider configuration, credential fingerprint and price expiry are rechecked. Count or generation failures remain uncertain and never automatically retry.

A successful synchronous response becomes an encrypted, request/policy/idempotency-bound `encryptedProviderReceipt` on the existing `researchJobs` row. This inherits that collection's actual privacy provenance and erasure. Receipt persistence requires the unchanged attempted job and provider policy. Its text can be observed as provisional analysis, but the job remains `UNKNOWN` for financial reconciliation: estimated usage cost is not a verified invoice, reservation stays held, and status never silently settles it. A process crash before receipt persistence likewise leaves the permanent unresolved financial checkpoint and cannot trigger a second generation attempt.

Private request/receipt/results expire with the existing seven-day research job retention. Shared unresolved financial checkpoints and reserved client ledgers have no automatic expiry; settled financial evidence uses the existing bounded retention. Erasing a personal research job does not release an unresolved reservation or permit a resend. No separate Gemini response collection or invented operator-to-customer linkage is added.

Environment configuration remains absent/default off. Enabling requires `LUMIN_PLATFORM_ENABLED`, `LUMIN_PAID_RESEARCH_ENABLED` and `LUMIN_GEMINI_TEXT_ENABLED`, plus the deployment-owned `LUMIN_GEMINI_TEXT_POLICY_JSON` and secure `LUMIN_GEMINI_API_KEY`. The model is allowlisted; the policy contains token ceilings, conservative integer cents-per-million rates and reviewed pricing timestamps/source. Policy or credential changes require restart and fresh approval. No MCP key setter exists. Real provider credentials, current price review, explicit research budget approval and separate staging acceptance remain external release prerequisites.
