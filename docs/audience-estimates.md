# Bounded audience estimates

The original `ads_estimate_audience_size` name is preserved with a strict client-scoped replacement. Supply an explicit registered account root, optional selected connection and `targeting_spec` containing a country list from US/CA/GB/AU/NZ, optional adult age range and optional Meta gender codes. Opaque targeting, private audiences, cities, interests and arbitrary fields are excluded from this subset. The read uses a selected USER or system-user Marketing credential, current registered READ authority and external-client eligibility. It creates no grants, targeting lookup records or ads.

The fixed request calls `/{account}/delivery_estimate` with REACH and the typed targeting specification. Current SDK fields are `estimate_mau_lower_bound`, `estimate_mau_upper_bound` and `estimate_ready`. The legacy `users_lower_bound`/`users_upper_bound` names are not used. Missing or unready results remain null; invalid ranges, errors and unexpected pagination deny the observation. Monthly audience bounds are estimates, not actual reach, performance, delivery eligibility or business outcomes.

Provider egress and the final response are revalidated. The final atomic repository checkpoint binds the actual selected encrypted credential, original membership/registry/grants, global operator indices and actual provider-user privacy/lifecycle locks. No model-provided authority or default-account fallback exists.

Primary contracts: [Meta delivery estimate reference](https://developers.facebook.com/documentation/ads-commerce/marketing-api/reference/ad-account/delivery_estimate), inspected October16,2026, currently displaying v25 with July7,2025 update; [pinned current AdAccount SDK](https://github.com/facebook/facebook-python-business-sdk/blob/efd8423a2e595ea8d4c04eb824ce113f2f1d68cd/facebook_business/adobjects/adaccount.py) and [AdAccountDeliveryEstimate fields](https://github.com/facebook/facebook-python-business-sdk/blob/efd8423a2e595ea8d4c04eb824ce113f2f1d68cd/facebook_business/adobjects/adaccountdeliveryestimate.py). Source validation is distinct from live Meta permission/endpoint acceptance.
