# Client WhatsApp QR management

Current primary sources checked on 2026-10-16: the [QR guide](https://developers.facebook.com/docs/whatsapp/business-management-api/qr-codes), updated May 21, 2026 with v26 examples, and its linked [QR management API](https://developers.facebook.com/documentation/business-messaging/whatsapp/reference/whatsapp-business-phone-number/whatsapp-business-qr-code-management-api). The API reference identifies whatsapp_business_management, a verified phone and a valid system-user credential. Lumin additionally requires its inspected client-specific BISU identity and separately reviewed owner/dual-account assignment.

Five canonical tools list, inspect, create, update and delete codes under the exact registered phone's message_qrdls edge. Codes are exactly fourteen uppercase alphanumeric characters; messages are at most 140 Unicode characters. Every mutation requires a separately human-approved exact plan and a durable single attempt. Update/delete first perform an exact phone-scoped code lookup; a code is never a substitute for another phone's authority. List results are bounded to 25 and explicitly report incomplete inventory when Meta supplies a next page. Provider URLs/cursors are not followed.

Creation supports PNG or SVG. Only the returned HTTPS Meta FBcdn image URL is returned as image metadata; it is never fetched by this client, and credentials, alternate hosts, userinfo, ports and fragments are rejected. The exact wa.me deep link is checked against the actual code. A QR link does not establish opt-in, send a message, prove delivery or provide scan analytics; Meta explicitly excludes QR analytics.

The original four WhatsApp QR tool names map to the same guarded contracts when platform mode is enabled. Original flag-off behavior is preserved. Legacy creation without an image-format option produces a reviewed PNG request. Caller fields are strictly validated, never silently discarded. Verification uses fake providers and native MCP human-approval journeys; no real QR code was created or deleted.
