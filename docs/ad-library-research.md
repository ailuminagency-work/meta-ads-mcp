# Public archive research boundaries

`marketing_search_ad_library` is a separate default-off READ adapter. It uses fixed `https://graph.facebook.com/v26.0/ads_archive`, bearer authorization, a server-owned field projection and a maximum25record firstpage. The selected registered client AD_ACCOUNT is only local tenant/client/credential authorization context. Returned public Page/archive IDs create no grants, registry assets, billing relationships or permission to manage competitors.

Primary sources: [current Ads Archive reference](https://developers.facebook.com/docs/graph-api/reference/ads_archive/), [Archived Ad fields](https://developers.facebook.com/docs/marketing-api/reference/archived-ad/), and [official onboarding/coverage](https://www.facebook.com/ads/library/api). The onboarding page states political/social/election ads worldwide over7years and ads of any type delivered to UK/EU over1year. The API parameter note refers to EU-only commercial coverage; the adapter conservatively supports six EU countries (DE,FR,ES,IT,IE,NL), ALLads, delivery-date windows no longer than31days within the pastyear. It rejects US commercial requests. This cannot establish Amazing Decks Seattle competitor coverage.

Identity/location confirmation and app-specific Ad Library access require actual human review through the durable manual eligibility UI. Selected USER `ads_read` is a conservative Lumin credential requirement; the primary archive pages do not state that permission as the endpoint's exact minimum. Current authorization is checked before request and again before returning data. Provider eligibility, successful access and real coverage remain external validation gates.

The adapter returns bounded public ad text and documented Page/date metadata only. Provider snapshot URLs may contain access tokens, so neither snapshot URLs nor paging URLs are returned, fetched, persisted or logged. Empty data does not prove absence of competitors. Archive delivery dates do not establish performance, spend, conversions or profitability. No automatic pagination, downloads or campaign changes occur.

Optional paid research uses the separately implemented [durable research job runtime](paid-research-jobs.md): protected human cost review, client monthly reservation, one durable local attempt and explicit financial reconciliation. Concrete bounded Gemini text and separately pinned community/Apify-maintained public-ad acquisition adapters exist in source. Deployment selection and flags default off, credentials remain absent, and no actual paid run has occurred. The older preparePaidResearch compatibility helper remains HOLD-only and is not the execution path.

The pinned one-attempt acquisition adapters deliberately provide neither provider idempotency nor a verified free status/cost reconciliation endpoint. A returned sample is not an invoice: UNKNOWN reservations and permanent no-resend checkpoints remain held rather than claiming zero cost, settling automatically or retrying. Gemini bounded text likewise has no provider hard dollar cap or idempotency claim. Future adapters must prove their own coverage, terms, credential destination, billing/cost bounds and any claimed free reconciliation contract; a missing vendor feature must not be invented. Existing archived observations can be compared or listed under current scoped authorization without a new provider request. Local fixtures do not establish actual vendor access or coverage.
